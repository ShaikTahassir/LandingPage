# Urban Skillet + Mountop Nutrition Landing Page

A responsive restaurant selector designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `restaurant-landing-page`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. GitHub will display the public website URL after deployment.

## Ordering links

- Urban Skillet Northridge: https://urbanskilletcd.square.site/#most-popular
- Mountop Nutrition: https://www.mountopnutrition.com/

Both links open in a new tab, allowing visitors to return to the landing page easily.

## Customize

- Edit restaurant text and links inside `index.html`.
- Edit colors in the `:root` section at the top of `styles.css`.
- Replace emoji artwork later with restaurant photos or logo files if desired.
